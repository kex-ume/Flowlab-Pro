Available variables

  • {% verbatim %}{{ log }}{% endverbatim %} — the CalibrationLog (certificate_no, asset_id, date_of_issue, result, notes, expanded_uncertainty, coverage_factor, calibration_due, …)
  • {% verbatim %}{{ company }}{% endverbatim %} — CompanyProfile (company_name, logo, abbreviation, accreditation_statement …)
  • {% verbatim %}{{ addresses }}{% endverbatim %} — company address rows (label, address)
  • {% verbatim %}{{ readings }}{% endverbatim %} — CalibrationLogReading rows (instrument_reading, uut_reading, error, unit)
  • {% verbatim %}{{ standards }}{% endverbatim %} — reference standards used (name, serial_no, certificate_no, last_calibrated, calibration_due_date)
  • {% verbatim %}{{ specs }}{% endverbatim %} — instrument specification rows (spec_name, spec_value)
  • {% verbatim %}{{ narrative }}{% endverbatim %} — resolved traceability paragraph from Settings
  • {% verbatim %}{{ conformity }}{% endverbatim %} — environmental conformity verdict or None
  • {% verbatim %}{{ date_received }}{% endverbatim %}, {% verbatim %}{{ previous_log }}{% endverbatim %}, {% verbatim %}{{ total_pages }}{% endverbatim %}
